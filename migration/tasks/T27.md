# T27. Global navigation and footer

## Goal

Render `siteSettings.nav` and `siteSettings.footer` on every page, including the mobile nav. Match the live chrome with the refine rules in `DESIGN.md`. Do not edit `Base.astro`.

This task depends on T26. T26 mounts `<Header />` and `<Footer />` and passes `language` and `pathname`. It also leaves the two files as empty landmarks. Replace those landmarks. Do not take `Base.astro` back. If the props are missing, stop and write that in the Handoff.

The `siteSettings` query lives in this directory, for example `apps/web/src/components/site/settings.ts`. T20 still owns `apps/web/src/lib/sanity/**`, so the query does not go there.

## Inputs

- `apps/studio/schemaTypes/documents.ts` for `siteSettings`, and `apps/studio/schemaTypes/objects.ts` for `link`
- `DESIGN.md`, the Navigation section, and the `nav-link` tokens
- The T26 mount in `apps/web/src/layouts/Base.astro`
- The public site `https://www.zawlodzki.pl/`, read only

## Steps

1. Load `.claude/skills/good-css/SKILL.md` before any CSS. Keep the styles inside `apps/web/src/components/site/`. Do not edit `apps/web/src/styles/**`. T08 owns that tree. A missing `siteSettings` document renders the empty landmarks and does not throw, so a build with no such document still succeeds.
2. Read the `siteSettings` document for the `language` prop. Render each link `label` and `href` from that document. Do not hardcode the live menu. The header is the sticky Paper bar from `DESIGN.md`. The logo points at `/` for PL and at `/en/` when `language` is `en`. Below 992px the links collapse into a Paper sheet behind a control that opens and closes. At 1280 the links are visible without that control. The current item uses `aria-current` and Ink. Do not use Webflow blue `#0082f3`.
3. On 2026-10-23 the live header puts a primary pill at the right of the desktop nav, and the mobile sheet repeats a contact link. Use the `siteSettings.nav` items for both. If the rendered list differs from the live header, record the difference in the Handoff. Do not add a schema field. The same day's live page has a promo line above the nav. `siteSettings` has no field for it. Leave the promo line out.
4. Render `siteSettings.footer` in the footer. The live footer HTML has one control, label `Zarządzaj zgodami`, with `data-c15t-open`. If that label is already a footer link, put the attribute on that control. If the document has no such link, add that one control. Do not add a second one.
5. Prove the chrome with verify-web at 1280 and at 375. Do not deploy. This task does not close T20. T20 still owns the open crawl differences, including the missing chrome, until its own gate is repeated.

## Handoff

Każda strona z `Base.astro` dostaje pasek nawigacji i stopkę z opublikowanego dokumentu `siteSettings` dla języka strony. Etykiety i adresy pochodzą z dokumentu. `Base.astro` nie był ruszany. Przycisk zgody w stopce jest jeden.

### Zmiany

`apps/web/src/components/site/settings.ts` czyta `siteSettings` przez `sanityQuery` z `apps/web/src/lib/sanity/client.ts`. Zapytanie GROQ jest w tym pliku i nie prosi o `defaultSeo`. Cache trzyma obietnicę per funkcja zapytania i język, zanim zapytanie się rozstrzygnie. `null` daje widok `empty`. Zły kształt albo język inny niż prop zostaje odrzucony i zostaje w cache.

Ostatnia pozycja `nav` jest pigułką. Wcześniejsze pozycje są linkami. Pusta tablica `nav` zostawia logo bez listy. Pierwsza etykieta stopki po `trim`, równa `Zarządzaj zgodami`, dostaje `data-c15t-open` i znika z obu tablic linków. Dalszy duplikat zostaje zwykłym linkiem. Opublikowany dokument PL takiej etykiety nie ma, więc stopka dokłada jeden przycisk.

`aria-current="page"` porównuje ścieżkę dokładnie. `/` pasuje tylko do `/`. Hash, `mailto` i `tel` nie są bieżące. Adres bezwzględny jest bieżący tylko dla `zawlodzki.pl` i `www.zawlodzki.pl`. Jeden końcowy ukośnik jest ignorowany przy porównaniu. Wyrenderowany `href` zostaje przyciętym stringiem z dokumentu. Build statyczny podaje `Astro.url.pathname` jako plik HTML (`/kontakt.html`, `/index.html`). `requestPath` zdejmuje sufiks `.html` i mapuje `/index` oraz pustą ścieżkę na `/`. Logo jest bieżące, gdy ta ścieżka równa się stronie głównej języka.

`disclosure.ts` ma stany `closed` i `open`. `bindNavDisclosure` zapisuje tylko `aria-expanded`. Klik przełącza. Escape zamyka i woła `preventDefault` tylko wtedy, gdy menu było otwarte. Drugie podpięcie tego samego elementu nic nie dodaje. Nagłówek z samym logo też jest zapamiętany i nie dostaje słuchacza klawiatury. Nie ma `matchMedia`.

`Header.astro` i `Footer.astro` dostają `language` i `pathname` z montowania T26. Pusty widok zostawia `<header>` albo `<footer>`. Gotowy nagłówek to lepki pasek Paper, logo, jeden przycisk i jedna lista. Przycisk jest poprzednim bratem `nav`. Poniżej 992px lista jest schowana, dopóki `aria-expanded` nie jest `true`. Od 992px przycisk znika, a lista jest rzędem. Szerokość `992px` w media query stoi w miejscu `--breakpoint-lg`, bo custom property nie działa w warunku media. Stopka to jedna zawijana lista. Linki są Slate, bieżąca pozycja jest Ink, pigułka jest Atlas Blue. Nie ma `#0082f3`. Hover jest w `@media (hover: hover) and (pointer: fine)`. Fokus zostaje przy pierścieniu z `base.css`.

`LogoMark.astro` wstawia `logo-mark.svg` jako bieżący kolor. Nazwa dostępna logo to ukryty tekst `logo Grzegorz Zawłodzki`. Adres logo to `/` dla `pl` i `/en` dla `en`.

Dokument EN nie istnieje. Strona z `language` `en` dostałaby puste landmarki. Tras EN jeszcze nie ma.

Tekst zadania podaje adres logo `/en/`. `trailingSlash` w Astro to `never`, więc adres to `/en`.

Podgląd, który montuje `Base.astro`, nadal czyta opublikowany dataset. Ścieżka zapytania jest poza `owns` tego zadania.
