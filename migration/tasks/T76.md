# T76. Web performance from the Lighthouse audit

## Goal

Lighthouse 12 (mobile, 2026-11-12) on staging `zawlodzki-web.zawlodzki.workers.dev` scores 98–100 on every page except `/newsletter` (82), but every page weighs 2.8–5 MB. Most of that weight is third-party. This task removes the avoidable part without touching tracking (GTM stays as it is; deferring it is out of scope).

## Requirements

1. **Turnstile on demand.** `LeadForm.astro` injects `turnstile/v0/api.js` on page load, and the challenge downloads 1.7–3.5 MB per page (twice on `/`, which has two forms). Load it only when a form comes near the viewport or gets focus. Forms must stay behind Turnstile: the token still has to exist before submit, and the no-JS fallback is unchanged.
2. **No layout shift from the widget.** On `/newsletter` the Turnstile iframe (about 73 px) appears inside the signup form after load and pushes the post list down (CLS 0.257). The widget must not move content that is already on screen.
3. **LCP image.** The first post card on `/newsletter` is the LCP element and has `loading="lazy"`. The first card of a post list loads eagerly with `fetchpriority="high"`.
4. **Responsive Sanity images.** Images are served at up to 1600 px with no `srcset`. Add `srcset`/`sizes` so small slots download small files.
5. **Render-blocking CSS.** Five separate stylesheets block first paint. Inline them where Astro's heuristics allow.
6. **Consent banner contrast.** The c15t banner's legal link fails WCAG AA contrast. Fix it from site CSS (the loader `cmp-v1.js` itself stays unchanged).
7. **Console errors.** Lighthouse logged `ERR_CONNECTION_REFUSED` for `pagead2.googlesyndication.com/ccm/collect`. Check whether this comes from the site or the test machine, and record the result.

## Done when

- [x] Turnstile script and challenge are not requested on load; a form still gets a token and submits.
- [x] `/newsletter` mobile CLS < 0.1 and LCP image not lazy.
- [x] Sanity `<img>` tags carry `srcset` and `sizes`.
- [x] Fewer render-blocking stylesheets than before.
- [x] c15t legal link passes the Lighthouse contrast audit.
- [x] The pagead console error is explained in Handoff.
- [x] `pnpm --filter web build` and tests are green; before/after Lighthouse numbers are in `migration/lanes/platform/out/t76-web-perf/`.

## Handoff

Branch `task/T76-web-perf`. Before/after numbers are in [results.md](../lanes/platform/out/t76-web-perf/results.md).

What changed:
- **Turnstile on demand** (`LeadForm.astro`). Explicit render mode. `api.js?render=explicit` (about 28 KB) loads on the first `focusin` or `pointerdown` in a form. The widget is rendered and the challenge runs on submit, and the post waits for the token. A retry after an error removes the old widget and renders a fresh one. Every form still needs a token. The no-JS path is unchanged.
- **CLS** comes out at 0 on `/newsletter`. Nothing renders into the form before submit.
- **LCP image.** `PostList` takes `eager`. `Sections.astro` passes it for the first two sections, so the first card loads eagerly with `fetchpriority="high"`. `MediaImage` with `eager` and the first eager `PostCards` card also get `fetchpriority="high"`.
- **srcset.** `site.ts` exports `sanityImage()`, which builds a srcset ladder of 160, 320, 480, 640, 960 and 1280 px plus the full width, capped at 1600. `src` is unchanged, so JSON-LD and Markdown image URLs do not move. `sizes` values match the rendered widths measured on staging: logos `8rem`, testimonial logos `10rem`, post cards `24rem`/`25rem`, post body `47rem`, post hero `58rem`, half-column media `50vw`.
- **Render-blocking CSS.** Diagram styles were 22 KB gzip, bundled into every page. Each generated diagram now has `<style is:inline>` placed above its markup, so the CSS ships only on pages that render that diagram. Its selectors were already scoped by `[data-diagram]`. `port-diagrams.mjs` generates the same layout. `build.inlineStylesheets: 'always'` inlines the remaining roughly 15 KB gzip of site CSS, which leaves 0 render-blocking requests.
- **Font swap.** Faster first paint exposed a font-swap shift (CLS 0.195 under devtools throttling). The new metric-matched `Satoshi Fallback` (Arial) and `Erode Fallback` (Georgia) faces in `fonts.css`, with size-adjust and ascent/descent overrides, bring it back to 0. This needed a contract change: the `tokens.json` font stacks list the fallbacks. `tokens.css` was regenerated and `decisions.md` has a row.
- **Consent contrast** (`styles/consent.css`, imported in `Base.astro`). The c15t `--legal-links-*` variables are overridden with `html:root`, which beats the loader's runtime `:root`. Light mode uses primary-60 and dark mode uses primary-20. `cmp-v1.js` is untouched.
- **CSS budget** (`check-dist.mjs`). Inlined CSS would have read as 0 B. The budget is now the heaviest page's linked stylesheets plus its inline `<style>` blocks. Before T76 every page linked every CSS file, so the 42,000 B limit means the same thing. Result: main 38,855 B → T76 24,966 B.

**Console errors.** `pagead2.googlesyndication.com/ccm/collect` → `ERR_CONNECTION_REFUSED` comes from the test machine. Its DNS (router 10.0.0.1) resolves that host to `0.0.0.0`, which is an ad blocker. The live Webflow site logs the same 4 errors. Nothing in the site to change.

Deviations: the task grew beyond the original five points by the diagram CSS split, the font fallbacks with their contract change, and the budget rewrite. The first two were needed for the CSS item and to keep CLS at 0 once CSS stopped blocking. The budget rewrite was needed so the gate keeps measuring CSS. Requirement 2 was met by not rendering the widget before submit, not by reserving space.

Live-key limitation: production n8n and the live Turnstile key were not used. The continuation below verifies real browser → Turnstile test service → Worker → local mock receiver delivery, without stubbing form fetch or Siteverify. Check one real submit on staging after deploy. A visible interactive challenge (rare, for suspicious traffic) now appears inside the form after the user presses submit.

Follow-up outside scope: GTM/gtag (about 511 KiB before consent) is still the largest remaining cost (TTI ~10 s on staging). Deferring it touches tracking and needs the owner's decision.
