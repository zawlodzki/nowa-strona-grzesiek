## Goal

This is the second Asana page Grzesiek asked for. `/audyt-procesow-asana` has six scenes. The problem scene was rebuilt in T100, so this task rebuilds the five audit steps in the calm style.

## Context

- This task builds on T96–T100 (PRs #107, #108, #109, #112 and #114), all in review. It uses `ListScene.astro` from T100. The branch starts from the T100 branch, so those PRs need to be merged first.
- What each step covers, from the page copy:
  - Step 1: map the real processes and compare them with what is in Asana. The difference is usually half of the findings.
  - Step 2: templates, roles, deadlines and rules: which are used, which were left after the first month, and where responsibility is split between three people.
  - Step 3: how the team uses its open projects today.
  - Step 4: automations, reports, the portfolio view, integrations and AI: what is set up, what is set up wrong, and what is missing.
  - Step 5: the report, with problems ranked by priority. Each is marked as either fixed during the workshops or bigger work with a quote.
