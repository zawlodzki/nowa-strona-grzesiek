## Goal

This is the second Asana page Grzesiek asked for. `/audyt-procesow-asana` has six scenes. The problem scene was rebuilt in T100, so this task rebuilds the five audit steps in the calm style.

- This task builds on T96–T100 (PRs #107, #108, #109, #112 and #114), all in review. It uses `ListScene.astro` from T100. The branch starts from the T100 branch, so those PRs need to be merged first.
- What each step covers, from the page copy:
