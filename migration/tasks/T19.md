## Handoff

**What changed.**
- `apps/web/src/preview/` is a separate Astro SSR application using the existing content parser, route table and renderer. Each authorized request reads Sanity drafts without a CDN or process cache. Incomplete unrelated drafts are excluded at the preview boundary. An incomplete selected page gives a safe 422; an unavailable upstream gives 502.
- `wrangler.preview.jsonc` configures `zawlodzki-web-preview`. The Worker authenticates before serving HTML or assets, adds noindex and private/no-store headers to every response, disallows robots, and rejects form POSTs. Runtime bindings hold the read token and auth credentials.
- Studio imports `presentation.ts` with PL/EN page and post locations. Sanity's preview-secret enable endpoint creates a one-hour signed HttpOnly cookie bound to the origin and dataset. Basic Auth remains available for direct access. Editable text carries source maps for overlays.
- `site.ts` exposes a request reader while its production loader stays cached. `RouteView.astro` accepts an explicit Site and preview noindex flag. Production remains static.
- README.md documents deployment, the initial Workers Builds Git connection, the Sanity webhook filter and the timed publish check. The hook URL belongs only in the external webhook configuration.
