# T13. Sitemap, robots, RSS, llms.txt and redirects

## Goal

Discovery files and every redirect from url-map.csv.

## Inputs

- migration/contracts/url-map.csv

## Steps

1. Sitemap index per language with lastmod from content; thank-you and cookies pages excluded.
2. `/blog/rss.xml` at the same path; `llms.txt` generated from content.
3. Redirects generated from url-map.csv rows with action redirect-301, including the pagination parameter rule.

## Done when

## Handoff

**What changed**

- `apps/web/src/worker/redirects.gen.mjs` generates `redirects.data.ts` from the `redirect-301` rows of `contracts/url-map.csv`. It accepts only `/path` and `/path?param=*` shapes and fails on anything else. Regenerate with `node apps/web/src/worker/redirects.gen.mjs`.
- `apps/web/src/worker/redirects.ts` looks up the exact, case-sensitive path in a Map and answers one 301. Path rules keep the query string. The pagination rule matches `/blog?f95bbc04_page=<n>`, drops that parameter and keeps the others.
- `apps/web/src/worker/index.ts` calls `legacyRedirect` before the assets fetch, so redirects still get `X-Robots-Tag` off production.
- `apps/web/src/pages/sitemap/_content.ts` runs one GROQ query against the public `production` dataset at build time, skips `seo.noindex` documents and parses the result at the boundary. A fetch error or a malformed document fails the build.
- `apps/web/src/pages/sitemap/_render.ts` holds pure renderers. The routes are `sitemap.xml.ts` (index), `sitemap-[lang].xml.ts`, `robots.txt.ts`, `blog/rss.xml.ts` and `llms.txt.ts`.
- `.claude/skills/verify-web/features/` gains `discovery-files.md`, and `canonical-urls.md` now covers the legacy and pagination redirects.

**Deviations**

- `owns` gained `apps/web/src/worker/index.ts` (the one-line hook; no open task owns it) and `.claude/skills/verify-web/features/**` (the recipes must change with the behavior). Board check passes.
- Thank-you and cookies pages leave the sitemap through `seo.noindex`, not a path list. The importers must set `noindex` on `/podziekowanie-konsultacja`, `/podziekowanie-newsletter` and `/lista-cookies-i-identyfikatorow`.
- The sitemap has no hreflang alternates yet. EN arrives in T24/T25.
- llms.txt is generated from person, services, pages and posts. The live file's hand-written "Kluczowe fakty" and "Kontakt" sections have no Sanity model, so they are gone.
- RSS item titles are the post title, without the live ` | Grzegorz Zawłodzki` suffix. The channel title is "Grzegorz Zawłodzki".
- The RSS feed is served as `application/xml`. Static assets set the type from the extension.

**Follow-ups**

- T18 should absorb `pages/sitemap/_content.ts` into `lib/sanity/`.
- T15/T16: imported documents must pass the discovery parser (slug, title, description, valid dates), or the build fails.

- The sitemap lists only what Sanity holds, and `/` and `/blog` come from Sanity pages or the synthetic blog entry. Recheck the sitemap against url-map `in_sitemap=yes` rows after T16 and T18.
