# T02. Monorepo and Astro scaffold on Cloudflare Workers

## Goal

A buildable `apps/web` (Astro, static output) deployed to a `workers.dev` staging URL, plus CI.

## Inputs

- migration/PLAN.md section 3
- migration/contracts/url-map.csv

## Steps

1. pnpm workspace with `apps/web` and an empty `apps/studio` placeholder (package.json only). TypeScript strict.
2. Astro current stable, static output, `trailingSlash: 'never'`. Settle by experiment which `build.format` plus Workers static assets `html_handling` serves `/o-mnie` with 200 and no redirect, and `/o-mnie/` with 301 to `/o-mnie`. Record curl output in `migration/lanes/platform/out/trailing-slash.md`.
3. Worker `zawlodzki-web` with static assets on `workers.dev` only. Never attach a custom domain or touch DNS. Without Cloudflare auth, prove it with `wrangler dev` and record the blocker.
4. Base layout with `<html lang="pl">`, placeholder home and 404 pages.
5. GitHub Actions: install, typecheck, build, `python3 -I migration/tools/tasks.py check`.
6. Load the `good-css` skill (or follow `.claude/skills/good-css/SKILL.md`) before writing any CSS.

## Done when

- [ ] `pnpm build` passes in CI.
- [ ] Trailing-slash note contains observed curl output.
