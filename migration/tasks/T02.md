# T02. Monorepo and Astro scaffold on Cloudflare Workers

## Goal

A buildable `apps/web` (Astro, static output) deployed to a `workers.dev` staging URL, plus CI.

## Inputs

- migration/PLAN.md section 3
- migration/contracts/url-map.csv

## Steps

1. pnpm workspace with `apps/web` and an empty `apps/studio` placeholder (package.json only). TypeScript strict.
2. Astro current stable, static output, `trailingSlash: 'never'`. Settle by experiment which `build.format` plus Workers static assets `html_handling` serves `/o-mnie` with 200 and no redirect, and `/o-mnie/` with 301 to `/o-mnie`. Record curl output in `migration/lanes/platform/out/trailing-slash.md`.
3. Worker `zawlodzki-web` with static assets on `workers.dev` only. Never attach a custom domain or touch DNS. Without Cloudflare auth, prove it with `wrangler dev` and record the blocker.
4. Base layout with `<html lang="pl">`, placeholder home and 404 pages.
5. GitHub Actions: install, typecheck, build, `python3 -I migration/tools/tasks.py check`.
6. Load the `good-css` skill (or follow `.claude/skills/good-css/SKILL.md`) before writing any CSS.

## Handoff

**Changed.** pnpm workspace (`package.json`, `pnpm-workspace.yaml` with `allowBuilds` for esbuild, sharp, workerd). `apps/web` is Astro 7.4.1, static output, `trailingSlash: 'never'`, `build.format: 'file'`. `apps/studio` is a placeholder `package.json` for T07. CI runs in `.github/workflows/ci.yml`.

**Worker.** `zawlodzki-web` uses static assets with `html_handling: drop-trailing-slash`, `not_found_handling: 404-page` and `run_worker_first: true`. `src/worker/index.ts` does two things. It upgrades the 307 canonical redirects from static assets to 301 (`canonical.ts`). On any host other than `www.zawlodzki.pl` it adds `X-Robots-Tag: noindex, nofollow`.

**Staging.** https://zawlodzki-web.zawlodzki.workers.dev. No custom domain and no DNS change. Deploy with `pnpm --filter web deploy`, which requires `wrangler login` on the Cloudflare account.

**Evidence.** `migration/lanes/platform/out/trailing-slash.md` holds a 4-config matrix measured with curl plus the chosen config. On staging, `/index.html` returns 301 to `/`, `/nope` and `/O-MNIE` return 404, and `/` carries `x-robots-tag: noindex, nofollow`.

**Deviations.**
- TypeScript is pinned to 6.x because `astro check` refuses TypeScript 7.
- Static assets alone answer canonical redirects with 307, so the Worker runs first on every request. Traffic is small, so the cost is negligible. Recheck this if the free-plan request limits ever matter.
