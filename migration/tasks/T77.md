# T77. Declare content usage preferences in robots.txt

## Goal

Allow search indexing and use in AI answers. Decline AI model training. Publish the preference in the site's own robots.txt, without changing crawler access or adding Markdown negotiation.

## Done when

- [x] The production host's robots.txt serves one Content-Signal directive with all three preferences and preserves the sitemap and crawl access.
- [x] Non-production hosts still disallow crawling.

## Handoff

The robots generator adds one Content-Signal line to the wildcard group. It preserves crawl access and the sitemap URL.

The local Wrangler build served HTTP 200 and text/plain for both hosts. With Host set to www.zawlodzki.pl, the body contained the signal, Allow: /, and the canonical sitemap. With Host set to preview.zawlodzki.pl, the body contained only the wildcard group and Disallow: /. The preview response kept X-Robots-Tag: noindex, nofollow. All 11 discovery tests passed. No production settings changed.
