# T42. Implement the T41 CTA audit

## Goal

Grzesiek approved the T41 recommendations ("Sugestie dotyczące CTA są dobre, wdroż je"). Source of truth: `migration/lanes/design/out/t41-cta-audit/README.md` (merged in #60).

Implement:
1. Every existing CTA with verdict "change" in "Teksty istniejących CTA": new label exactly as proposed (e.g. "Zacznijmy wdrożenie" -> "Umów rozmowę o wdrożeniu" / "Umów rozmowę o wdrożeniu AI", "Umów audyt…" -> "Umów rozmowę o audycie…", "Zapisz się na pierwszą grupę" -> "Zapytaj o udział w programie", "Zacznijmy współpracę" -> "Porozmawiajmy o współpracy").
2. The new CTAs from the top-10 and per-page sections that need only Sanity content (ctaBand, feature.cta, Portable Text link), at the recommended positions, with the recommended copy. Respect "at most one CTA per ~2 screens"; on /blog/ai-w-sprzedazy a single calm inline link, no banner.

Rules:
- Production Sanity is a human gate. Do NOT write to Sanity. Produce one dry-run script `migration/tools/import/pages-t42-cta-patch.mjs` that reads a fresh export file and emits revision-guarded (`ifRevisionID`) mutations, plus a readable change list (page, field path, old -> new) in `migration/lanes/design/out/t42-cta/README.md`.
- No apps/** changes. If an item needs code (button inside `tabs`, PromoCard custom label, a label hardcoded in a component), list it under "Wymaga zmian w kodzie" with file paths; do not implement it here (several blocks are owned by T40).
- Skip any CTA text that T40 already patches (the /audyt-sprzedazy main CTA "Umów audyt sprzedaży" and pricing badge texts): check `migration/tools/import/pages-t40*` on its branch/PR and note overlaps instead of duplicating.
- Kurs AI: do not copy any purchase/presale link without confirming it's current; leave a note.

Verification: apply the patch to a local copy of the export and render with verify-web (`scripts/web.sh up` on the assigned port, wrangler dev --local, never astro dev) using that data if the toolchain supports a local dataset override; otherwise screenshot affected pages before and render diffs of the patched JSON. Evidence in `out/t42-cta/`.
