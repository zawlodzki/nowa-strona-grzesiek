# T68. Browser smoke tests in CI: forms, consent, accessibility

## Goal

Browser behaviour here is verified by hand per task, with evidence files (`verify-web`, ad hoc Playwright scripts under `migration/lanes/**/out/`). Nothing re-checks it on the next change. `nowa-strona-ola` runs a Playwright suite with axe in CI on every push.

Add a small, stable suite that protects the things that cost money or legal exposure when they break: lead forms, consent defaults, and basic accessibility. Keep it small; this is a smoke test, not the Ola suite.

## Steps

1. Add Playwright and `@axe-core/playwright` to `apps/web`. Chromium only in CI to start. Serve the built site through the real Worker (`wrangler dev`), as the `verify-web` skill does, not `astro preview`.
2. Forms: with the Turnstile test keys and `form-mock-receiver.mjs` as the webhook, submit the contact form and the newsletter form. Assert the redirect, that the receiver got the Webflow-shaped envelope with all 32 attribution fields, and that an empty or invalid form posts nothing. Block every request to the production n8n host in the test fixture, and fail the test if one is attempted.
3. Consent: on first load the inline Consent Mode v2 defaults are `denied` for analytics and ads, the loader script tag for `consent.zawlodzki.com/assets/cmp-v1.js` is present, and no GTM or analytics request leaves before consent. Stub the c15t backend; the real one returns 403 to origins that are not allow-listed.
4. Accessibility: run axe (WCAG 2 A/AA, 2.1 AA, 2.2 AA) on the home page, one service page, the blog index, one post and the contact page. Record existing violations. Fail CI only on rules that pass today; list the rest as a follow-up with counts.
5. Layout: no horizontal overflow at 320 px on the same five pages.
6. Add the suite to CI after the build, with the report uploaded as an artifact on failure. Keep the job under ten minutes.

## Notes

- The build in CI reads the production dataset, so page content can change under the tests. Assert structure and behaviour, not copy.
