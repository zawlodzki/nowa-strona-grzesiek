# T45. Second CTA button in course tabs

## Goal

Leftover from the T41 CTA audit and the T42 dry-run package (`migration/lanes/design/out/t41-cta-audit/README.md`, `/kurs-ai-w-sprzedazy`; `migration/lanes/design/out/t42-cta/README.md`, "Wymaga zmian w kodzie"): an optional second course button, "Zapytaj o pracę na Twoim CRM", inside the tabs. T42 put the first course CTA ("Zapytaj, czy kurs pasuje do Twojego procesu") in a `ctaBand` and did not add a button in the tabs block. Tabs.astro is free after T43.

Today `apps/studio/schemaTypes/blocks.ts` (`tabs` / `tabItem`) has no CTA fields, and `apps/web/src/components/blocks/Tabs.astro` renders no buttons. T43 also recorded that the then-current build of `/kurs-ai-w-sprzedazy` had zero `data-tabs` blocks; confirm against current content.

1. Add an optional secondary CTA per tab (`label` + `href`; reuse the existing `link` object, do not edit `objects.ts`) in the tabs schema, and an optional primary CTA field if one is needed so the secondary can sit next to it. Render the secondary as a secondary-style button next to the primary. Fields are optional: pages without this content (e.g. Sales Atlas) must stay unchanged.
2. CTA copy names a realistic, low-commitment next step. For the course, the leftover label is "Zapytaj o pracę na Twoim CRM" pointing at `/kontakt`. Do not invent or copy a purchase/presale link.
3. Production Sanity writes are a human gate. Do not apply any write. Deliver content as an `ifRevisionID`-guarded dry-run patch script (`migration/tools/import/pages-t45*`) that is not applied, plus a readable change list in `migration/lanes/design/out/t45-tabs-cta/`.
4. T39 owns `apps/studio/sanity.types.ts` and `apps/studio/schemaTypes/objects.ts`. Do not edit those. If generated types lag, extend the local component type and note the regen in Handoff. If a contract file or `_ds/blocks-a.astro` is required, add it to `owns` in the PR and say why. If the course program is not actually a `tabs` block, still ship the schema and render, document that finding, and prove the button on a page that does have tabs (local fixture is fine; no production write).
