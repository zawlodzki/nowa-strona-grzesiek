# T102. CRM audit page diagrams in the calm scene style (steps 1–5)

## Goal

After the Asana pages, Grzesiek asked to continue with the following subpages. `/audyt-crm-pipedrive` has six scenes. The problem scene (`zw-pipedrive-problem`) was rebuilt in T97, so this task rebuilds the five audit steps in the calm style.

## Context

- This task builds on T96–T101 (PRs #107, #108, #109, #112, #114, #115), all in review. It uses `ListScene.astro` from T100. The branch starts from the T101 branch, so those PRs must be merged first.
- Page copy, by step:
  - Step 1, the sales process: how you really sell, compared with what is in Pipedrive. The difference is usually half of the findings.
  - Step 2, data and fields: how complete each field is, which fields are dead, which are missing, and where data diverges enough to trip an automation.
  - Step 3, configuration, automations and integrations: what is set up, what is set up wrong, and what is missing.
  - Step 4, how salespeople work in the system: real open deals.
  - Step 5, the report: problems ranked by priority, what gets fixed during the workshops and what needs bigger work, with a quote.
