# T47. Pre-cutover SEO fixes from the staging audit

## Goal

The 2026-11-12 SEO audit of staging against the Webflow inventory found gaps that must close before T22. The user asked for all of them to be fixed.

1. Bing Webmaster verification: Webflow's head carries `<meta name="msvalidate.01">`; the new head does not, and DNS only holds the Google verification. Emit the same tag on every page.
2. `/kurs-ai-w-sprzedazy` lost its `Course` + `CourseInstance` nodes and renders as `Service` because the Sanity model has no course fields (T18 handoff). Add optional course fields to the `service` document, map them to the existing `course` page kind, and prepare the production content as an unapplied, `ifRevisionID`-guarded dry-run patch. The write itself needs the user's yes.
3. Blog post card thumbnails (`/blog`, related posts, post-list block) have `alt=""`; Webflow used the post title. Restore it.
4. Hashed `/_astro/*` assets are served with `max-age=0, must-revalidate`. Serve them immutable.
5. Minor: add `apple-touch-icon`; serve `llms.txt` and `robots.txt` with `charset=utf-8`; restore the security headers Webflow sent (`X-Content-Type-Options`, `X-Frame-Options`, `frame-ancestors`).
6. `/newsletter` has 159 words against 200 on live, a row missing from `diff-accepted.md`. Find what dropped and report; fix only if it sits in owned files.
