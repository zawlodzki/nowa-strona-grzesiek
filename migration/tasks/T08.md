# T08. CSS foundation from tokens

## Goal

Tokens as CSS custom properties, base typography, layout primitives.

## Inputs

- DESIGN.md
- migration/lanes/design/out/tokens.json

## Steps

1. Promote `tokens.json` to `migration/contracts/tokens.json` and record the decision in `decisions.md`.
2. Load the `good-css` skill. Write tokens as custom properties, fluid type, no `html { font-size: 20px }` hack.
3. Self-host Satoshi and Erode as WOFF2 subsets (latin-ext). Replace Material Icons with inline SVG.

## Done when

- [x] No TTF and no Google Fonts request on the staging home page. (Proven on the local Worker under `wrangler dev`; staging shows it once this is deployed.)
- [x] Type scale renders identically at 1440px and 390px to DESIGN.md values.

## Handoff

### What changed

- `migration/contracts/tokens.json` is the promoted T04 file (git move, only `$description` changed). Decision row 13 records it.
- `apps/web/src/styles/build-tokens.mjs` compiles the contract into `tokens.css`: 141 custom properties. Hex colours become `oklch()` and the script fails if any of them does not convert back to the same hex. `semantic.*` drops its prefix (`--text-body`, `--surface-page`, `--border-focus`). Typography composites split into `--typography-<role>-family|size|weight|leading|tracking`. `--check` fails when `tokens.css` is stale.
- `apps/web/src/styles/fonts/` holds Erode and Satoshi as variable WOFF2 (upright and italic, 24 to 37 KB each, down from 85 to 130 KB TTF). `subset.sh` rebuilds them from the same Webflow CDN TTFs the live site serves, cut to Latin and Latin Extended. `fonts.css` declares them with a matching `unicode-range`, `font-display: swap` and weight ranges 300 to 700 (Erode) and 300 to 900 (Satoshi).
- `base.css` holds the good-css reset and the type roles. `h1` is Display, `h2` is Headline (heading-l), and so on down to `h5`/`h6` as heading-xs. `.type-<role>` classes give the same look without changing the heading level. Links, `:active`, hover inside `(hover: hover)`, and a global `:focus-visible` outline (3px Atlas Blue, 2px offset, the live ring done with `outline`).
- `layout.css` holds the primitives `.content-grid` (with `.breakout` and `.full-width`; content track = 1248px minus both fluid gutters, like the live `.container`), `.section`, `.flow`, `.prose` (68ch and the blog H2/H3 rules), `.auto-grid` and `.with-icon`.
- `global.css` fixes the cascade order `reset, base, layout, components, utilities` and imports the rest.

### Deviations

- `apps/web/src/layouts/Base.astro` is outside `owns` (T02, done). Without it the stylesheet never reaches a page, so I added three imports and two `<link rel="preload">` tags for the upright fonts. Nothing else in it changed.
- `scrollbar-gutter: stable` from the good-css reset is left out. With it, Chrome sets `100vw` to 1425px in a 1440px window with classic scrollbars, and every role renders 0.3% small (Display 54.84px instead of 55). Measured in the browser pane: `100vw` = 1425 with `stable`, 1440 with `auto`.
- Material Icons: nothing here loads them. The inline SVG icons belong in a component, which T09 owns (`components/ui/**`). The live site uses nine glyphs: arrow_forward (370 uses), check (354), expand_more (142), chevron_left (80), phone, email, close, person_add, mail. `.with-icon` sizes them by the text.
- I did not hand the code to a subagent. The change is small and tied to measurement, so I wrote it and verified it myself.
