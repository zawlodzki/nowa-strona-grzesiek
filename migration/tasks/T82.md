# T82. Anchor targets clear the sticky header

## Goal

Jumping to a section anchor (`/#kontakt`, `/#crm`, `/#ai`, `#cennik`, `#faq`, `#opinie`) must show the section heading below the sticky header, not under it.

## Context

Visual audit of staging, 2026-11-13, 1440 px: after loading `/#kontakt` the H2 top sits at 64 px while `header.site-header` ends at 72 px. Same for `/#crm`. The blocks set `scroll-margin-top: 7.5rem` on `:is(h2, h3)[id]`, but the ids used by in-page links sit on the `<section>` (`BlockSection.astro`), which has no scroll margin. Section padding (64 px desktop, 48 px mobile) is smaller than the header height.

## Requirements

- Fix it once, globally, in `base.css` (for example `scroll-padding-top` on the scroll container, sized from the header height at each breakpoint). Do not add per-block rules.
- The heading must be fully visible with breathing room at 390, 768 and 1440 px, with and without the promo bar.
- Keep the existing per-heading `scroll-margin-top` working for blog TOC links (no double offset that pushes the heading far down the viewport).
- Follow the `good-css` skill.

## Done when

- [x] Through `wrangler dev`, `/#kontakt` and `/#crm` at 390 and 1440 px show the heading fully below the header. Record heading top and header bottom in Handoff, plus screenshots.
- [x] A blog TOC link on a post still lands with the H2 visible and not more than about 2 lines of empty space above it.
- [x] `pnpm test` and the build pass.

## Handoff


Implemented globally in `apps/web/src/styles/base.css`: `section[id]` gets a logical scroll margin matching the header's logo (44/55px), twice its 8px bar padding, and hairline border. The existing 992px header breakpoint is mirrored. Section padding provides breathing room. Heading margins and the scroll container are unchanged, so blog offsets do not accumulate.
