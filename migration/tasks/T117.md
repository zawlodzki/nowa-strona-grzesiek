# T117. Mobile navigation as a native popover

## Goal

Below 992 px the header's `.site-nav` has `display: none` and opens only when `disclosure.ts` sets `aria-expanded="true"` on the toggle. Without JavaScript the mobile navigation cannot be reached. The menu does not close on a click outside it, and Escape is handled by a document-wide `keydown` listener that runs on every page.

The `navbar` guide in the `modern-web-guidance` skill (`npx -y modern-web-guidance@latest retrieve "navbar"`) recommends one `<nav>` landmark that contains the menu button with `popovertarget` and the link list with `popover="auto"`. The browser then provides opening without script, light dismiss, Escape and focus return. The guide says: "Do not add document-level click-outside, Escape or focus-restoration handlers."

Found in the modern-web-guidance audit of 2026-11-15. Follow `good-css`. This is a refinement, not a redesign: the open menu should look and animate as it does now.

## Requirements

1. Put the toggle inside `<nav>`, immediately before the list. Give it `popovertarget` pointing at the list and `aria-controls`. In the narrow layout the list is a `popover="auto"`. Keep the decorative SVG `aria-hidden` and the visually hidden accessible name.
2. In the wide layout (992 px and up, or a measured fit per the guide if that stays simple) the same list renders inline and has no `popover` attribute. Sync the attribute from script with `setAttribute`/`removeAttribute`, and reopen the menu if a resize removes the attribute while it is open and the layout is still narrow. Without script, the narrow layout must still open the menu.
3. Remove the document-level Escape handler. Remove `disclosure.ts` and its test if nothing else uses them, or reduce them to the layout sync.
4. Keep the current animation through `@starting-style`, `:popover-open`, and `transition-behavior: allow-discrete` as a separate property (see T116), scoped to `prefers-reduced-motion: no-preference`. Include `overlay` in the transition.
5. Position the popover under the header. If you use `anchor()`, put a plain fallback declaration before it (the guide's Fallbacks section). No polyfill: Popover is Baseline.
6. Add `apps/web/e2e/nav.spec.ts` covering: the menu opens and closes by button, by Escape and by clicking outside it, with focus returning to the button; the menu opens with JavaScript disabled; the wide layout shows inline links and no menu button. Update `axe-baseline.json` only if the axe results change, and explain why in Handoff.

## Done when

- [ ] On mobile the menu works without JavaScript and closes on Escape and on a click outside it.
- [ ] No document-level `keydown` listener remains for the nav.
- [ ] Desktop navigation looks unchanged. Mobile opening and closing look as before, with `verify-web` screenshots at 375 px and 1280 px.
- [ ] `nav.spec.ts`, the existing e2e suite, `pnpm --filter web build` and `tasks.py check` pass.
