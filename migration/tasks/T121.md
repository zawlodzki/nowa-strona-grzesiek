# T121. Cross-document view transitions between pages

## Goal

Optional polish. Navigation between pages is an instant full-page swap. A cross-document view transition (`@view-transition { navigation: auto; }`) gives a short cross-fade between same-origin pages with no JavaScript, and browsers without support simply navigate as now. See the `cross-document-transitions` and `consistent-cross-document-transitions` guides in the `modern-web-guidance` skill, plus the `animate` and `animation-performance` skills.

Found in the modern-web-guidance audit of 2026-11-15. This is a design decision: the owner approves or rejects the motion in PR review. Design scope is refine, not redesign.

## Requirements

1. Opt in with `@view-transition { navigation: auto; }` at the top level of `base.css`, only inside `@media (prefers-reduced-motion: no-preference)`.
2. Keep it quiet: a short root cross-fade with the existing motion tokens. Optionally give the sticky header a `view-transition-name` so it stays still while the content fades. No slide or directional animations.
3. It must not delay or block navigation. Check that it does not interfere with the c15t consent banner, the header mobile menu (T117), anchor links to in-page sections, or back/forward cache.
4. Record a short screen capture or a set of frames with `verify-web` at 375 px and 1280 px for the owner to judge.

## Done when

- [ ] Same-origin navigations cross-fade in Chrome and Safari. With reduced motion there is no transition.
- [ ] The header does not flicker. Consent banner, mobile menu and in-page anchors work as before.
- [ ] The owner has seen the capture in the PR. `pnpm --filter web build` and `tasks.py check` pass.
