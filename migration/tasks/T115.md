# T115. Remove invalid review markup from the homepage

Search Console reported two reviews of the homepage's “Usługi” offer catalog. Google does not support `OfferCatalog` as the subject of a review rich result.

## Done when

- [x] The homepage emits its offer catalog without `Review` nodes, even when it has text testimonials.
- [x] Existing testimonial markup on other page kinds still passes its tests.
- [x] The task board validates.

## Handoff

- The homepage's single JSON-LD graph omits testimonial `Review` nodes and still includes the `OfferCatalog` subject of the original report. This applies to either language when a homepage is built.
- The regression test reproduced both invalid reviews before the fix and now passes. All six tests in `seo.test.mjs` pass, including the existing test for reviews on an ordinary page.
- The Astro check and a build from current Sanity content passed. The built homepage has zero `Review` nodes, compared with two on the live homepage. Both testimonial authors still appear in the built HTML. The build verified 117 HTML pages.
- After deployment, verify that the public homepage serves the corrected graph before starting the Search Console validation.
