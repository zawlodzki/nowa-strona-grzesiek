# T53. Editable form and newsletter texts

## Goal

Grzesiek cannot edit form field labels, placeholders, submit buttons, consent copy or the newsletter heading/legal line in Studio. The `contactForm` schema today has variant, heading, intro, calendar, consultation and channels; `newsletterSignup` has only `body`. Labels such as "E-mail", "Telefon", "Temat rozmowy", "Wyślij zapytanie", "Zapisuję się", the contact newsletter checkbox, the contact privacy note, "Newsletter Sales Atlas" and the newsletter legal paragraph are hardcoded in `ContactForm.astro`, `NewsletterSignup.astro` and `LeadForm.astro`.

Depends on T47 (typegen files), T51 (`blocks.ts` and typegen) and T52 (typegen). Do not touch `sanity.config.ts` or `documents.ts`.

No production dataset write: add optional schema fields and keep the current copy as code defaults so existing documents stay valid and the site looks the same until an editor fills a field.

## Requirements

1. Add optional Studio fields for the hardcoded form and newsletter texts (field labels and placeholders, required-marker text, submit labels, waiting label "Zaczekaj chwilę…", contact privacy note, newsletter checkbox label, newsletter heading, newsletter legal paragraph including the two legal links). Existing CMS heading/intro/body/calendar/consultation/channel fields stay as they are.
2. The page must use the CMS value when present and the current copy when the field is empty. Do not change the visible default wording.
3. `formId`, n8n endpoint wiring and Turnstile stay in code, not in Sanity.
4. Run typegen. Prove a contact form and a newsletter signup still match current copy with empty new fields (home and `/kontakt` and `/newsletter` or `/blog` are enough), and that filling a field in local Studio would override the default. Evidence in `migration/lanes/cms/out/t53-form-copy/`. Stop dev servers at the end. Do not deploy Studio.

## Done when

- [ ] Editors can change form and newsletter texts in Studio through optional fields.
- [ ] Current copy remains the default; pages with empty new fields look unchanged.
- [ ] formId, n8n and Turnstile are still only in code.
- [ ] Typegen is updated. `tasks.py check` passes; PR opened with status `review`. Do not merge. No production Sanity write.
