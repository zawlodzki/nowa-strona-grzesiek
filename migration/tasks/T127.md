# T127. Consistent brand suffix in page titles

## Goal

`seo.title` is rendered verbatim into `<title>`, `og:title` and `twitter:title`. On 2026-11-20, after T126 shortened 25 titles to fit the 60-character Studio limit, the 108 published titles were inconsistent: 71 ended with " | Grzegorz Zawłodzki", 2 with " | Zawłodzki", 2 placed the name elsewhere (`/wspolpraca`, `/polityka-prywatnosci`), and 33 had no brand. On live Webflow, 97 of the 106 crawled titles carry the full suffix.

On 2026-11-20 the owner chose: the web build appends " | Grzegorz Zawłodzki" to every title, stored titles hold only the bare text, and the Studio limit stays 60 characters on that bare text. A limit of 60 − 21 = 39 was rejected because 32 of the 108 bare titles are longer than 39 characters and would need rewriting again.

## Requirements

1. One helper adds the suffix for `<title>`, `og:title` and `twitter:title`, for routed pages and for utility pages that pass a bare title. It must not double a suffix that is already there.
2. Hardcoded titles in the web build (blog index and blog pagination) hold the bare text.
3. Studio describes the rule on the SEO title field and warns when an editor types the suffix. The 60-character limit is unchanged.
4. A generator writes an `ifRevisionID`-guarded patch that strips the brand from every stored SEO title, including `siteSettings` default SEO. Keep the old → new list and the patch in `migration/lanes/cms/out/t127-title-suffix/`.
5. Back up with `node migration/tools/backup-sanity.mjs` and get the owner's explicit yes at the moment of the production write.
6. JSON-LD, canonicals, hreflang and every `keep` URL stay unchanged.

## Done when

- [ ] Unit tests cover the helper and `buildMeta`, and the web tests pass.
- [ ] A build against production data shows the suffix exactly once in the `<title>` of every page in `dist`, with evidence in `migration/lanes/cms/out/t127-title-suffix/`.
- [ ] Backup recorded, owner's approval recorded, patch applied, every revision guard matched, Studio validation clean.
- [ ] JSON-LD snapshot tests and `check-dist` pass. `tasks.py check` passes.
