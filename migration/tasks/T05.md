# T05. DNS zone file for Cloudflare import and DNSSEC sequence

## Goal

A verified zone ready to import into Cloudflare, without changing any external system.

## Inputs

- migration/00-inventory/dns/
- migration/PLAN.md section 8

## Steps

1. Add `migration/lanes/tracking/private/` to `.gitignore`. The repo is public: no record values, DKIM keys or tokens in tracked files.
2. `zone-to-bind.py` turns `zone-zawlodzki.pl.csv` into a BIND file in `private/`, without NS records and without rows marked drop or stale.
3. `dig` every record against the OVH nameservers; list mismatches by name and type in `dns-plan.md`.
4. List DNS-only vs proxied records (names only). Check `dig DS` and `dig DNSKEY`; write the exact DNSSEC disable-and-wait sequence.

## Done when

- [ ] BIND file exists locally and matches dig for every kept record.
- [ ] dns-plan.md has no record values.
