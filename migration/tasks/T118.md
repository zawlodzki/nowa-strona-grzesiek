# T118. Current page and selected tab not shown by color alone

## Goal

Two state indicators rely on color only, which fails WCAG 1.4.1:

- In the header, `.nav-link[aria-current='page']` only changes the text color.
- In `Tabs.astro`, the selected tab (`aria-selected="true"`) is marked only with a background. Forced colors mode removes backgrounds, so the indicator disappears. The repo has no `forced-colors` rule anywhere.

The `navbar` and `tabs` guides in the `modern-web-guidance` skill say: "Do not indicate the current page with color alone (WCAG 1.4.1). Ensure the color of the visual indicator has a contrast of at least `3:1`", and for tabs: "Add a shape, such as an underline. Draw the underline with a border on a pseudo-element. DO NOT use `box-shadow` or a background". The `navbar` guide also asks to "adapt custom borders and current-page indicators under `forced-colors: active`".

Found in the modern-web-guidance audit of 2026-11-15. Use the `impeccable` and `good-css` skills. Design scope is refine, not redesign: add a quiet, on-brand shape (for example an underline or a side bar) that matches the existing tokens.

## Requirements

1. Give the current nav link a non-color indicator, both inline (desktop) and in the mobile menu, with at least 3:1 contrast against its background. It must not change the link's size or shift the layout.
2. Give the selected tab a non-color indicator drawn with a border on a pseudo-element, not a background or a box-shadow. Keep the current background as the primary look.
3. Add `@media (forced-colors: active)` rules so both indicators, the focus rings and the pill/CTA borders stay visible. Use system colors (`Highlight`, `LinkText`, `CanvasText`).
4. Prove the result with `verify-web` screenshots at 375 px and 1280 px, plus Chrome's forced-colors emulation.

## Done when

- [x] The current nav link and the selected tab are identifiable in grayscale and in forced colors mode, with screenshots.
- [x] The indicators have at least 3:1 contrast and cause no layout shift.
- [x] The axe e2e check passes. `pnpm --filter web build` and `tasks.py check` pass.
