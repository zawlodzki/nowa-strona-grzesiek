# T41. CTA placement audit

## Goal

Grzesiek feels the page contents have too few CTAs. Audit every public page on staging https://zawlodzki-web.zawlodzki.workers.dev (service/offer pages, home, /o-mnie, /sales-atlas-system, /newsletter, blog index and a sample of posts; compare with live https://zawlodzki.pl) and recommend where an additional CTA is worth adding inside the content.

Also audit the COPY of every existing CTA in the audited pages. A CTA must name the realistic next step with low commitment. "Bezpłatna konsultacja" and "Umów rozmowę o wdrożeniu AI" are valid. "Zacznijmy wdrożenie" wrongly implies starting a project before an initial conversation. For every existing CTA give current text, verdict (ok / change), a proposed Polish replacement, and a one-line reason. Apply this rule to all newly proposed CTAs. Add "Teksty istniejących CTA" to the README and include the worst offenders in the top-10 summary.

This task produces recommendations only. No changes to apps/**, no Sanity writes.

Deliverable: `migration/lanes/design/out/t41-cta-audit/README.md` with, per page:
- current CTAs (where, text, target) and long CTA-free stretches (sections/scroll depth),
- recommended new CTAs: exact position (after which section), type (inline button, CtaBand, PromoCard, contact link), suggested copy in Polish, target (contact form / Sales Atlas / newsletter / call), and priority (high/medium/low) with a one-line reason,
- whether it needs code (new block/variant) or only content in Sanity.
Plus a short top-10 summary ranked by expected impact, and annotated full-page screenshots (verify-web `shot` on port 8790) of the top 5 pages marking proposed spots.

Keep recommendations consistent with PRODUCT.md and DESIGN.md (tone, no spammy repetition: at most one CTA per ~2 screens of content).
