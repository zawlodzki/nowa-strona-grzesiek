# T59. Markdown versions of public pages at the same URL plus .md

## Goal

Every public page should also be available as Markdown at the same URL with `.md` appended, so agents can read the content without the HTML chrome. Grzesiek (2026-11-12, Europe/Warsaw): strony mają też generować się jako `.md` po dopisaniu `.md` do adresu, ze względu na łatwiejszy dostęp przez agentów.

Examples: `/sales-atlas-system.md`, `/blog/automatyzacja-sprzedazy.md`, `/polityka-prywatnosci.md`. Home is `/index.md` (not `/.md`). EN routes, when they exist, follow the same rule (`/en.md`, `/en/....md`).

This ships on staging only. Production deploy is a separate human gate. Do not merge.

## Design notes

- **Generate at build time** from the same Sanity content the HTML routes already load via `loadRoutes()` / `loadSite()`. Do not scrape HTML. The site is a static Astro build (`output: 'static'`, `trailingSlash: 'never'`, `build.format: 'file'`) served by the Cloudflare Worker in `apps/web/src/worker/index.ts` (`run_worker_first`, `html_handling: drop-trailing-slash`, `not_found_handling: 404-page`).
- **Portable Text and blocks → Markdown**, not an HTML round-trip. Posts have `body` as Portable Text. Pages have `sections` (hero, feature, contentSection, tabs, pricing, ctaBand, testimonials, promoCard, faq, logoStrip, richText, postList, contactForm, newsletterSignup, …). Render each block as structured Markdown (headings, paragraphs, lists, quotes, tables where they help). Tabs become a heading plus content per tab. Logo strips can be a list of names. Pricing can be a list or a Markdown table.
- **Each `.md` file should include:** title, description, canonical HTML URL, headings, body, links, and image alt text (`![alt](url)`; decorative images may use empty alt). Prefer absolute `https://www.zawlodzki.pl/...` URLs. Internal links may point at the target's `.md` URL when that target is a public route.
- **Exclude chrome:** no nav, footer, cookie banner, or form fields. For `contactForm` / `newsletterSignup`, a heading and a short description are enough; do not list inputs or endpoints.
- **Coverage:** emit a `.md` for every public route in `loadRoutes()` (pages, blog index, posts, legal pages, blog pagination if those routes exist, EN when present). Do not emit Markdown for `/404`, `/_ds/*`, `/api/*`, sitemaps, RSS, `robots.txt`, or `llms.txt` itself.
- **Routing and headers:** `/path.md` must serve the Markdown asset and must not be caught by a redirect meant for `/path`, nor fall through to the HTML 404 before the asset is tried. Trailing slash: `/path.md/` 301 to `/path.md`. Existing HTML redirects stay unchanged (for example `/konsultacja` → `/wspolpraca`). Serving `.md` for a path that is only a redirect source may 404; do not invent a new redirect table unless it is a thin, tested mapping from an existing redirect target to `target.md`.
- **`Content-Type: text/markdown; charset=utf-8`.** Set this in the Worker if the asset layer would otherwise send `text/plain` or something else.
- **`X-Robots-Tag: noindex` on `.md` responses, including production.** This is the default so Google does not index Markdown as a duplicate of the HTML page. State the choice in the PR. Off-production, the Worker already adds `noindex, nofollow` to every response; do not weaken that. Do not edit `apps/web/public/_headers` (T47 owns it).
- **`<link rel="alternate" type="text/markdown" href="...">` in the HTML head.** T47 currently owns `apps/web/src/layouts/Base.astro` and `apps/web/src/lib/sanity/seo.ts` — do not touch them. Add the link in `apps/web/src/seo/Seo.astro` (free). Home is `/index.md`. Pages that only pass a bare title to `Base` can stay without the link.
- **`/llms.txt`:** optionally list the `.md` URL for each entry (keep the existing HTML links and tests passing, or update the tests if the format grows). A short note at the top that Markdown is at the same path plus `.md`, with home at `/index.md`, is enough if you would rather not change the bullet shape much.
- **No new npm dependencies and no `pnpm-lock.yaml` edits.** T50 owns the lockfile. Write the converter in-repo under `apps/web/src/lib/markdown*`. If a package is truly unavoidable, set status `blocked`, explain under Handoff, and stop.
