# T113. Render a CTA band without heading or body as a plain button

## Goal

A `ctaBand` section that has only a button no longer renders as an empty blue band with the button pushed to the right. It renders the way the Webflow original did: a plain primary button directly under the preceding section's content.

## Context

Owner request, 2026-11-14, with a screenshot of an empty blue band holding only "Wybierzmy proces dla AI".

In the production dataset, five pages have a `ctaBand` with no `heading` and no `body`: /wdrozenie-ai-w-sprzedazy-b2b, /program-ai-dla-zespolu-sprzedazy, /audyt-ai-sprzedaz, /kurs-ai-w-sprzedazy and /sales-atlas-system. In the live Webflow HTML (inventory `live-site/html/`), none of these was a band. Each was a lone button (`ctas-wrapper`) right after the "Sprawdź czy moja usługa pasuje do Twojej firmy" checklist. The text-left, button-right band only existed for the closing "Zacznijmy od rozmowy" sections, which have a heading.

## Requirements

- In `CtaBand.astro`, when both `heading` and `body` are empty, render only the primary button, aligned with the content column, with no band surface.
- Pull it up to the preceding section, so it reads as part of that section and not as a lone section.
- Bands with a heading or body stay unchanged.

## Done when

- [ ] The five pages render the bare button under the preceding content, checked through `wrangler dev`.
- [ ] Bands with a heading (for example on / and /audyt-sprzedazy) are unchanged.
