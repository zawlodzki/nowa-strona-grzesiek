# T113. Render a CTA band without heading or body as a plain button

## Goal

A `ctaBand` section that has only a button no longer renders as an empty blue band with the button pushed to the right. It renders the way the Webflow original did: a plain primary button directly under the preceding section's content.

## Context

Owner request, 2026-11-14, with a screenshot of an empty blue band holding only "Wybierzmy proces dla AI".

In the production dataset, five pages have a `ctaBand` with no `heading` and no `body`: /wdrozenie-ai-w-sprzedazy-b2b, /program-ai-dla-zespolu-sprzedazy, /audyt-ai-sprzedaz, /kurs-ai-w-sprzedazy and /sales-atlas-system. In the live Webflow HTML (inventory `live-site/html/`), none of these was a band. Each was a lone button (`ctas-wrapper`) right after the "Sprawdź czy moja usługa pasuje do Twojej firmy" checklist. The text-left, button-right band only existed for the closing "Zacznijmy od rozmowy" sections, which have a heading.

## Requirements

- In `CtaBand.astro`, when both `heading` and `body` are empty, render only the primary button, aligned with the content column, with no band surface.
- Pull it up to the preceding section, so it reads as part of that section and not as a lone section.
- Bands with a heading or body stay unchanged.

## Done when

- [x] The five pages render the bare button under the preceding content, checked through `wrangler dev`.
- [x] Bands with a heading (for example on / and /audyt-sprzedazy) are unchanged.

## Handoff

**What changed.** `apps/web/src/components/blocks/CtaBand.astro` branches on `!heading && !body`. The bare variant renders the section with the `cta-bare` class and only a primary `Button`, with no `.band` surface. Two rules close the gap to the section above: `.section:has(+ .cta-bare)` gets `padding-block-end: var(--space-m)`, and `.section.cta-bare` gets `padding-block-start: 0`. No content changed in Sanity.

**Deviations.** None. Adding a heading and text to each band in Sanity was rejected, because the Webflow original had no text there. That would mean writing new copy.

**Evidence.** `wrangler dev` built from `7bfaf33` with this change (verify-web, port 8797):

1. All five pages answer 200 and contain one `section.cta-bare` holding `a.action.primary`. On /wdrozenie-ai-w-sprzedazy-b2b the button sits 24 px under the checklist "Sprawdź czy moja usługa pasuje do Twojej firmy", at the same left edge (16 px at an 800 px viewport). The 1280 px screenshot confirms it. On /sales-atlas-system the DOM measurement gives the same result (24 px gap, button left = content left = 21 px).
2. `/` and `/audyt-sprzedazy` still render one `.band` each and no `cta-bare` element. The headed bands on the other four pages ("Zacznijmy od rozmowy" and similar) also still render as `.band`.

Not checked: phone width.
