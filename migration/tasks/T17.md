# T17. Assets: re-host images to Sanity with alt text

## Goal

Every image from both Webflow CDNs in Sanity, with a URL map for rewriting.

## Inputs

- migration/00-inventory/webflow/assets.json
- migration/00-inventory/webflow/cms/blog.items.json

## Steps

1. Upload by content hash so re-runs skip existing assets.
2. Missing alt text: draft from context, flagged for human review.

## Done when

- [x] asset-map.json covers every website-files.com and uploads-ssl.webflow.com URL found in the inventory.

## Handoff

Implemented `migration/tools/import/assets.py` and `assets_test.py`. `asset-map.json` is the flat source URL map consumed by T15's `lib/assets.py`. Each entry records the actual Sanity asset ID, target URL, SHA-1, image/file kind, alt, review flag, project and dataset.

`plan` and `build` discover sources without writes. `upload` requires `SANITY_API_TOKEN`, refuses production, downloads into a private cache, groups by content hash and kind, reuses matching dataset assets, and writes the map atomically after each resolved group. `verify` re-harvests inventory, requires exact URL coverage, reads Sanity assets, and compares each source byte hash with its mapped target. Interrupted runs resume from the cache and dataset readback.

Commands from the repository root:

```bash
python3 -B -I migration/tools/import/assets.py plan
python3 -B -I migration/tools/import/assets.py upload --dataset development --cache-dir /tmp/T17-assets
python3 -B -I migration/tools/import/assets.py verify --dataset development --cache-dir /tmp/T17-assets
python3 -B -I migration/tools/import/assets_test.py
```

Deviations and follow-ups:

- The assets export uses public `s3.amazonaws.com/webflow-prod-assets/` sources, so discovery includes that exact bucket path as well as both named CDNs. Non-image sources are Sanity file assets, so fonts, scripts and other referenced files do not disappear from coverage. Raw inventory and downloaded bytes stay outside tracked output.
- Existing HTML/field alts take precedence over library alts. Variants inherit an available parent alt. Missing alts are filename-based Polish drafts, explicitly flagged. The 1,115 flagged URLs correspond to 1,071 unique assets. These are proposals, not visually verified descriptions.
- `altNeedsReview` is a map-only flag. T15's importer consumes the alt fallback but does not expose that flag in Studio. Editorial review remains required before final content acceptance. Rebuild/import posts with this map when ready to apply those fallbacks to stored content.
- All writes targeted `development`. Production import remains a human gate. Asset IDs derive from content, but target CDN URLs and dataset metadata are development-specific; generate the production map during the approved production import rather than treating these URLs as production output.
- Model the Domain separated source URL identity from content identity. Build the Lever produced the replayable CLI and checks. Prove It Works required real Sanity readback, source hashes and importer integration. Sequence Work into Verifiable Units kept discovery, upload, readback and rerun checks separate.
