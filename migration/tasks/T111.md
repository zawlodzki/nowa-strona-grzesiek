# T111. Unify CTA arrows and responsive button layout

## Goal

Give standalone CTAs and post card prompts the same arrow behavior. Let long labels wrap at normal size and center each pricing button within its card.

## Done when

- [x] Pricing links, form submits and the blog CTA use the shared button. Post cards keep one accessible link and share the arrow.
- [x] Buttons fit at 320, 390, 768 and 1440 px with stable hover geometry. Verify keyboard focus and reduced motion.
- [x] Verify in the local Worker. Form destinations, fields and wait behavior stay intact. No production submissions.
