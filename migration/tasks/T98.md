# T98. Salesforce service page diagrams in the calm scene style (problem and setup)

## Goal

Grzesiek asked to continue with the next subpage. `/szkolenie-i-wdrozenie-salesforce` has six scenes. T97 rebuilt the four shared CRM steps. Rebuild the last two, `zw-sf-problem` and `zw-sf-setup`, so that the whole page uses the calm style.

## Context

- This task builds on T96 (PR #107) and T97 (PR #108), both in review: the shared scene base, the header marker in `port-diagrams.mjs` and `sequence.ts`. Its branch starts from the T97 branch, so merge #107 and #108 first.
- Page copy: Salesforce lets you build almost anything, so it is easy to build too much. Companies end up with a system cut for a corporation, with dozens of fields, English settings and reports nobody opens. Salespeople go back to Excel while the licence keeps charging. Step 3 covers pipelines, permissions, team views, manager reports, basic automations and mail and calendar integration.

## Requirements

1. `zw-sf-problem`: the record grows with modules and fields until the team leaves it. Bars are drawn to scale and the scene ends on the loss in Error Red.
2. `zw-sf-setup`: step 3, the parts of the system switched on one by one. Build the switch list as a reusable `SwitchScene.astro` so `zw-crm-setup` can move onto it later.
3. Both scenes use `sequence.ts`, carry the T96 header marker, use only site tokens and work in the 320px slot.
4. Figures and names are placeholders until Grzesiek confirms them.

## Handoff

### What changed

- `SwitchScene.astro` (new): a reusable "set up the system" scene. It takes `diagram`, `modules` and `label` props and renders the modules in two columns (one under 30rem). Each module has a switch, and `sequence.ts` turns the switches on one by one. The closing number reads `n z N`.
- `ZwSfSetup.astro`: step 3 on the Salesforce page, built on `SwitchScene` with six modules: lejki, uprawnienia, widoki dla zespołu, raporty dla managera, automatyzacje, poczta i kalendarz.
- `ZwSfProblem.astro`: the problem, "it is easy to build too much". Modules land on the deal record one by one: Szansa sprzedaży 12 fields, + Obsługa klienta 50, + Marketing 84, + Wycena (CPQ) 140. The bars are cumulative and drawn to scale against 140, and the largest is Error Red. Then two red outcomes appear: "Raporty, których nikt nie otwiera" and "Handlowcy wracają do Excela". It closes on "Pól na karcie szansy · 140" in red.
- Both files carry the T96 header marker. `port-diagrams.mjs --check`: `52 diagrams, 0 file(s) stale, 0 unsized`.
- With T97 included, all six scenes on `/szkolenie-i-wdrozenie-salesforce` are in the calm style.
