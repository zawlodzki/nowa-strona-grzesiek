# T52. Logo: per-logo invert toggle

## Goal

White artwork (smmash, iimarbella, deky expo) is invisible on the light logo strip unless inverted. Today `LogoStrip.astro` hard-codes those three names. Grzesiek wants a boolean on each `logo` document so editors can invert any logo.

Depends on T47 because `documents.ts` is in T47's owns until that PR merges, and on T51 so typegen files (`sanity.types.ts`, `schema.json`) are not claimed twice.

This task is not a human gate. Adding the field is a schema/frontend change with a default that keeps current behaviour. Setting `invert` flags on production logo documents is a separate small write and needs Grzesiek's later yes. Do not write those flags in this task.

## Current code (inspect 2026-11-12)

- `logo` in `apps/studio/schemaTypes/documents.ts` has `name`, `image`, `url`, `kind`. No invert field.
- `apps/web/src/components/blocks/LogoStrip.astro` uses `const difference = new Set(['smmash', 'iimarbella', 'deky expo'])` compared to `logo.name` lowercased, plus a separate `small` set that is out of scope.
- Logos are loaded in `apps/web/src/lib/sanity/site.ts` (`*[_type == "logo"]`) and passed through `Sections.astro` as `ResolvedLogo` (`_id`, `name`, `url`, `image`) from `block-types.ts`.

## Requirements

1. Add a boolean on the `logo` document, titled in Polish (for example "Odwróć kolory"), default `false`.
2. `LogoStrip` must invert when the flag is true. Keep the name-based fallback for smmash, iimarbella and deky expo until production flags are set, so the site does not regress. Once a logo has the flag set, the flag wins. Do not invert other logos by name.
3. Thread the field through the site query, `ResolvedLogo`, and `Sections.astro`.
4. Run typegen. Do not touch `sanity.config.ts` (T50). Prove with screenshots of a logo strip that still shows the three white logos inverted, and of the new field in local Studio if you run it. Evidence in `migration/lanes/cms/out/t52-logo-invert/`. Stop dev servers at the end.

## Done when

- [ ] Each logo document has an invert boolean in Studio.
- [ ] The strip inverts when the flag is true, and still inverts the three known white logos by name while flags are unset.
- [ ] Typegen is updated. `tasks.py check` passes; PR opened with status `review`. Do not merge. No production Sanity write. No Studio deploy.
