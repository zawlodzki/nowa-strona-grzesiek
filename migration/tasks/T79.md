# T79. Advertise the blog feed in the homepage Link header

Expose the existing RSS feed in the homepage HTTP response so clients can find it without parsing HTML.

## Done when

- [x] The homepage returns a Link header with the RSS URL, alternate relation and RSS media type.
- [x] The target returns a valid RSS feed. An unrelated page does not carry this header.

## Handoff

The homepage advertises the existing RSS feed through the static asset headers.

The local Wrangler build returned HTTP 200 for `GET /` with the expected Link header on the canonical and preview hosts. The preview response kept `X-Robots-Tag: noindex, nofollow`. The feed returned HTTP 200 and parsed as RSS 2.0 with posts. The blog index and the feed response did not carry the homepage RSS Link header.
