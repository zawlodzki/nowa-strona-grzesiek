## Goal

After the homepage (T92, T96), Grzesiek asked to continue on the next subpage. `/szkolenie-i-wdrozenie-pipedrive` follows the homepage CRM funnel. It has six scenes: the problem and one scene for each of the five steps of the engagement. Rebuild them in the approved calm style.

## Context

- This task builds on T96 (PR #107, in review): the shared step track and the header marker in `port-diagrams.mjs`. Its branch starts from the T96 branch, so merge #107 first.
- `zw-pipedrive-problem` is also on `/audyt-crm-pipedrive`. `zw-crm-process`, `zw-crm-data`, `zw-crm-training` and `zw-crm-handoff` are also on `/szkolenie-i-wdrozenie-salesforce`. These scenes must not name a CRM vendor.
- JS budget (`check-dist.mjs`) sums every `.js` file site-wide: 7722/8800 B after T96. Small inline scripts do not count, but a scene script that imports `scene/timeline.ts` becomes its own file of about 0.45 KB. Six scene scripts would break the budget. The scenes here therefore share one declarative script.

## Requirements

1. `sequence.ts` (next to the scenes; `scene/**` stays with T96): one shared player for scenes marked `data-scene="sequence"`. It marks `[data-step]` elements done one at a time and counts the closing number from `data-value`. All motion comes from CSS transitions on `.is-done`, gated by `prefers-reduced-motion: no-preference`. It builds on `scene/timeline.ts` (play once below the fold; the end state is in the markup).
2. Rebuild the six scenes on it, following the approved direction recorded in T92: hairlines and type, Polish labels, site tokens only, no text in Signal Cyan, calm tempo, one closing number. Pipeline stages stay in one row (T96).
3. Each rebuilt file carries the header marker `port-diagrams.mjs no longer writes this file` (T96).
4. Names, values and dates are placeholders until Grzesiek confirms them.
